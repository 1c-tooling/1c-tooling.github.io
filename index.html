01 / eska

CLI для работы
с проектами 1С

eska связывает XML-выгрузку, Git и платформу 1С, используя инструменты, необходимые выбранному сценарию.

CLI · Rust
eska github.com/1c-tooling/eska
01

Подключает XML-выгрузку Конфигуратора к проекту.

02

Показывает Git-изменения на уровне объектов и модулей 1С.

03

Собирает .cf, .cfe, .epf и .erf.

04

Для отдельных сценариев нужны Git, Git LFS и платформа 1С с ibcmd; для patch — также 1cv8.

02 / установка

команды

Короткие адреса всегда ведут на установщик последней опубликованной версии.

Linux и macOS

  https://1c-tooling.github.io/eska/install | sh
›_

Windows

PowerShell

PS> powershell -ExecutionPolicy Bypass -c \
  "irm https://1c-tooling.github.io/eska/install.ps1 | iex"
