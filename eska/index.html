Установить eska

Выберите свою систему и выполните команду в терминале.

$

Linux и macOS

Shell

$ curl --proto '=https' --tlsv1.2 -LsSf \
  https://1c-tooling.github.io/eska/install | sh
›_

Windows

PowerShell

PS> powershell -ExecutionPolicy Bypass -c \
  "irm https://1c-tooling.github.io/eska/install.ps1 | iex"
